Existem 3 formas principais de incluir CSS em documentos HTML

CSS Externo:
    O CSS fica armazenado em um arquivo separado com extensão .css (ex: estilos.css). Ele é vinculado ao documento HTML através da tag <link> colocada dentro do <head>.

CSS Interno:
    As regras CSS são inseridas diretamente no cabeçalho do documento HTML, dentro da tag <style>, que fica dentro do <head>.

CSS Inline:
    As regras de estilo são declaradas diretamente no elemento HTML usando o atributo style="".
