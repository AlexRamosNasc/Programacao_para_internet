CSS:
CSS significa (Cascanding Style Sheets). Podemos traduzir CSS como Folhas de Estilo em  Cascata. O arquivo CSS é uma folha de estilo. É nela que iremos definir a aparência (ou o  estilo) de cada elemento HTML da nossa página.

"h1 {
    color: red;
    font-size: 36px;
    font-weight: bold;
}

h2{
    border: 1px solid blue;
}"
