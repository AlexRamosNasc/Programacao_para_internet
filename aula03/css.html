CSS

CSS é uma linguagem declarativa auxiliar a documentos HTML para estilizaçao de definiçao de comportamento. O CSS pode ser declarado de três formas distintas.

  1. na tag style, definida no cabeçario do HTML;
  2. em documentos externos por meio da tag link;
  3. inline no proprio elemento HTML.

CSS possui diversas formas de selecionar em quais elementos HTML uma regra será aplicada.

Seletores:
  • seletor por elementos;
  • * seletor universal.
  • ID identificador unico
  • Classes ou categorias
  • seletor por descendente " " A B
