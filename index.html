GIT

O Git é um sistema de controle de versoes

Comandos do Git

  • git init : inicializa um repositorio git
  • git status
  • git add arquivo.txt : adiciona o arquivo no stage
  • git commit -m "comentario" : cria um commit no repositorio local
  • git log : exibe os commits atual do repositorio local
  • git swtch "branch" : muda de branch
  • git swtch -c cira-nova-branch : muda de brach
  • git diff : exibe a diferenca do commit apontado por HEAD e worktree
